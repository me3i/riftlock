# Security Policy

Riftlock is a security assessment tool. Please use it only on systems you own or have explicit authorization to test.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/me3i/riftlock/security/advisories/new). Include the affected version or commit, a clear description of the issue, reproducible steps, and any relevant impact. Please do not open a public issue for an unpatched security vulnerability.

We will review reports and coordinate a fix and disclosure timeline with the reporter. This project is maintained on a best-effort basis; a response or fix timeframe is not guaranteed.

## Supported versions

Security fixes are generally made against the latest version on the `main` branch and the latest published release.
